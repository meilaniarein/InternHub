# InternHub

InternHub is a web application designed to help university students discover and organize internship opportunities in one platform.

## Background

Students often struggle to find internship opportunities because vacancy information is distributed across multiple platforms. InternHub aims to make the internship search process more organized and efficient.

## Objectives

- Help students discover internship opportunities.
- Provide search and filtering features.
- Allow students to save interesting internship vacancies.
- Help students review internship application records and statuses.
- Provide internship preparation resources.

## Main Features

- **Home:** Introduction to the InternHub platform.
- **Internship Listings:** Browse and search available internship opportunities.
- **Internship Details:** Review vacancy information.
- **Saved Internships:** View saved internship opportunities.
- **Applications:** Review internship application records and statuses.
- **Resources:** Access internship preparation materials.
